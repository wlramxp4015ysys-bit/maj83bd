# 🤖 لوحة تحكم بوت تيليجرام وسيرفر Backend الاحترافي لتطبيق A2 TV

نظام متكامل واحترافي يربط تطبيق الـ APK ببوت تيليجرام وسيرفر سحابي مكتوب بلغة Python عبر REST API خفيف وسريع، ومصمم خصيصاً لإدارة الأقسام والقنوات بكفاءة واحترافية عالية.

---

## 🌟 المميزات الاحترافية الجديدة لإدارة الأقسام والقنوات:

### 🗂️ 1. إدارة الأقسام الاحترافية (Categories Management):
* **تصفح شامل وتفاعلي**: عرض جميع الأقسام مع أعداد القنوات التابعة لها وحالة ربط السيرفر.
* **إعادة ترتيب الأقسام (Reorder Up / Down)**: تحريك أي قسم للأعلى أو للأسفل لتحديد أولويات ظهوره في واجهة التطبيق.
* **إخفاء / إظهار الأقسام (Toggle Visibility)**: إمكانية إخفاء أي قسم مؤقتاً من التطبيق دون حذفه بنقرة زر واحدة.
* **عرض قنوات القسم مباشرة**: زر مخصص داخل تفاصيل كل قسم لعرض وتصفح قنوات هذا القسم مع ترقيم الصفحات.
* **تفريغ قنوات القسم (Bulk Clean)**: حذف كافة القنوات التابعة لقسم معين دفعة واحدة مع رسالة تأكيد أمان.
* **حذف ذكي للقسم**: خياران لحذف القسم: إما حذف القسم مع كامل قنواته، أو حذف القسم ونقل قنواته لقسم عام لحمايتها.
* **تعديل متكامل**: تعديل اسم القسم، أيقونة الإيموجي، والسيرفر المرتبط به فورياً.

---

### 📺 2. إدارة القنوات المتقدمة (Channels Management Pro):
* **🔍 البحث الفوري والذكي (Smart Channel Search)**:
  - بحث سريع بالاسم (عربي وإنجليزي مع معالجة الحروف والهمزات) أو برابط البث.
  - إمكانية البحث المباشر بكتابة اسم القناة في شات البوت.
* **📂 تصفح القنوات حسب الأقسام (Browse by Category)**:
  - تصفح منظم لكل قسم على حدة مع ترقيم أنيق للصفحات (Pagination).
* **⚡ فحص سلامة ورابط البث (Stream Health Check / Ping)**:
  - فحص مباشر وسريع من البوت للرابط: كود الاستجابة (HTTP 200 OK)، زمن الاستجابة (Latency ms)، ونوع المحتوى.
* **🔘 تفعيل / تعطيل القناة (Active / Disabled)**:
  - إيقاف أو تشغيل القناة في التطبيق مؤقتاً دون حذفها.
* **✨ إدارة الجودات والسيرفرات المتعددة (Multi-Quality & Multi-Server)**:
  - استعراض كافة السيرفرات البديلة والجودات (4K, FHD, HD, SD, LOW) لكل قناة.
  - إضافة جودة جديدة أو سيرفر احتياطي بنقرة زر واحدة.
  - حذف أي جودة أو سيرفر بشكل مستقل.
* **🖼️ تعديل شعار القناة (Logo)**:
  - إدخال رابط الصورة (URL) أو رمز إيموجي يظهر كأيقونة للقناة.
* **⚙️ إدارة الرؤوس والحماية (Headers & DRM)**:
  - تخصيص `Referer` و `User-Agent` و `Origin` و `DRM Key` لتشغيل البثوث المحمية بنجاح.

---

### 💾 3. الاستيراد والتصدير والنسخ الاحتياطي (Backup, Import & Export):
* **📥 استيراد ملفات M3U مباشرة**:
  - إرسال أي ملف `.m3u` أو `.m3u8` إلى البوت مباشرة ليقوم بتحليله وتوليد الأقسام ودمج القنوات وجوداتها تلقائياً.
* **📥 استعادة النسخة الاحتياطية (JSON Restore)**:
  - إرسال ملف `.json` للبوت لاستعادة أو دمج قاعدة البيانات بكافة تفاصيلها.
* **📤 تصدير ملف تشغيل IPTV (M3U Export)**:
  - تحميل ملف `.m3u` جاهز ومكتمل لتشغيل القنوات على أي برنامج أو شاشة ذكية.
* **📤 تصدير نسخة احتياطية كاملة (JSON Export)**:
  - تنزيل ملف قاعدة البيانات بضغطة زر واحدة لحفظه بأمان.
* **🌐 رابط البث المباشر (Live M3U Link)**:
  - رابط عام لسحب قائمة القنوات الحية مباشرة من السيرفر.

---

### 📊 4. لوحة الإحصائيات الشاملة (System Dashboard):
* إجمالي الأقسام والقنوات وسيرفرات الـ API.
* عدد القنوات النشطة مقارنة بالمعطلة.
* عدد القنوات التي تحتوي على جودات وسيرفرات متعددة.
* توزيع أعداد القنوات على كل قسم من الأقسام.
* توزيع الجودات (4K, FHD, HD, SD...).

## 🚀 طريقة التشغيل:

```bash
./start_bot.sh
```
أو:
```bash
python3 telegram_bot/run.py
```

## 📡 روابط الـ API المتاحة للتطبيق:
- معلومات وحالة التطبيق: `GET /api/app-config`
- قائمة القنوات (مع الفلترة والبحث): `GET /api/channels?category=sports&q=bein`
- قائمة الأقسام (مع دعم الأقسام المخفية): `GET /api/categories`
- تحميل قائمة M3U المباشرة: `GET /api/export/m3u`
- إحصائيات النظام: `GET /api/stats`
- حالة وضع الصيانة: `GET /api/maintenance`
- فحص توفر تحديث: `GET /api/update?current_version=2`
- سيرفرات الـ API المسجلة: `GET /api/channel-apis`
- ملفات التحديث المباشرة: `GET /static/app.apk`
